#2

Crop PDF

Estimate

2 days

Plan

Pro



Why build this now



Crop is one of the top-requested PDF tools globally and already unblocked in PyMuPDF. The only missing piece is a visual crop UI and the exposed endpoint. Positioned as Pro to drive upgrades from free-tier users who need it for scanned documents.

Backend — FastAPI / PyMuPDF



# POST /api/pdf/crop

# Body: { file: UploadFile, pages: list[int] | None, x0, y0, x1, y1: float }



import fitz # PyMuPDF



def crop_pdf(data: bytes, rect: fitz.Rect, pages: list[int] | None) -> bytes:

doc = fitz.open(stream=data, filetype='pdf')

for i, page in enumerate(doc):

if pages is None or i in pages:

page.set_mediabox(rect) # non-destructive crop

# Optional: also set CropBox for viewer compatibility

page.set_cropbox(rect)

buf = io.BytesIO()

doc.save(buf, garbage=4, deflate=True)

return buf.getvalue()



The set_mediabox call is non-destructive — the original page content is preserved outside the crop rectangle and can be restored by setting a new mediabox. Expose a 'restore original' option by storing original page dimensions in the response metadata.

Frontend — React (Tauri)



Render the first page as a PNG thumbnail (you already have PDF→Images). Overlay a draggable/resizable crop rectangle using CSS resize or a lightweight library (react-rnd). On confirm, POST the pixel coordinates converted to PDF units (pt). Show a before/after comparison in the result panel.

#3

Page Numbers / Header & Footer

Estimate

3 days

Plan

Pro



Why build this now



RTL page numbering is uniquely valuable to Arabic users — no free tool handles right-aligned Arabic numerals correctly. This is a strong Pro differentiator because Western tools like iLovePDF offer it in English only. Bundling an Arabic font (Noto Naskh Arabic) makes this the only tool Arabic users trust for this task.

Backend — FastAPI / PyMuPDF



# POST /api/pdf/add-page-numbers

# Body: { position: 'bottom-right'|'bottom-left'|'bottom-center'|'top-right'...

# format: '{n}'|'{n} / {total}'|'Page {n}',

# font: 'NotoNaskhArabic'|'Helvetica',

# size: float, color: [r,g,b], start_from: int, rtl: bool }



FONT_PATH = Path('assets/fonts/NotoNaskhArabic-Regular.ttf')



def add_page_numbers(data: bytes, opts: PageNumOptions) -> bytes:

doc = fitz.open(stream=data, filetype='pdf')

total = len(doc)

for i, page in enumerate(doc):

n = i + opts.start_from

text = opts.format.replace('{n}', str(n)).replace('{total}', str(total))

rect = page.rect

# Position mapping

positions = {

'bottom-right': fitz.Point(rect.width - 72, rect.height - 36),

'bottom-left': fitz.Point(36, rect.height - 36),

'bottom-center': fitz.Point(rect.width / 2, rect.height - 36),

'top-right': fitz.Point(rect.width - 72, 36),

}

page.insert_text(

positions[opts.position],

text,

fontfile=str(FONT_PATH) if opts.rtl else None,

fontname='NotoNaskhArabic' if opts.rtl else 'Helvetica',

fontsize=opts.size,

color=tuple(c/255 for c in opts.color),

render_mode=0,

)

buf = io.BytesIO()

doc.save(buf, garbage=4, deflate=True)

return buf.getvalue()



Bundle Noto Naskh Arabic (OFL license, free) in your assets/fonts/ directory. For header/footer text beyond page numbers, use insert_text() on a header/footer region (top 60pt or bottom 60pt of each page). Provide a text template field with {n}, {total}, {date} substitution variables.

Frontend — React (Tauri)



UI: position picker (visual diagram of 8 positions), font selector (Arabic / Latin), number format dropdown, start page and start number inputs, color picker, live preview showing the first page with numbering applied. RTL toggle auto-selects Arabic font and flips alignment.

#4

Invert Colors

Estimate

1 day

Plan

Pro



Why build this now



Students and heavy readers frequently request dark-mode PDFs. This is a 1-day build with outsized perceived value — users feel like they're getting a premium feature. It also pairs naturally with your Reading Speed Trainer and Book Library, making Pro feel cohesive.

Backend — FastAPI / PyMuPDF



# POST /api/pdf/invert-colors

# Body: { file: UploadFile, pages: list[int] | None }



def invert_pdf_colors(data: bytes, pages: list[int] | None) -> bytes:

doc = fitz.open(stream=data, filetype='pdf')

for i, page in enumerate(doc):

if pages is None or i in pages:

# Rasterize → invert → re-embed as image page

mat = fitz.Matrix(2, 2) # 2x render scale for quality

pix = page.get_pixmap(matrix=mat, alpha=False)

pix.invert_irect() # in-place invert

# Replace page content with inverted image

img_pdf = fitz.open('pdf', pix.pdfocr_tobytes())

page.show_pdf_page(page.rect, img_pdf, 0)

buf = io.BytesIO()

doc.save(buf, garbage=4, deflate=True)

return buf.getvalue()



The rasterize-and-replace approach works universally but increases file size. For text-layer PDFs, a more elegant approach is to add a black overlay rectangle with 'difference' blend mode via PyMuPDF's draw_rect — this preserves the text layer and keeps file size small. Offer both modes: 'Smart invert (text-only PDFs)' and 'Full invert (all PDFs)'.

Frontend — React (Tauri)



Simple tool: upload → invert all or select pages → download. Show a dark-mode preview thumbnail. Optionally expose a 'warm dark' mode (sepia-like) by applying a color matrix after inversion. No complex UI needed — ship simple first.

#5

PDF to Excel / Extract Tables

Estimate

6 days

Plan

Pro



Why build this now



Arabic-language PDFs containing financial tables, government reports, and academic data are extremely common and notoriously hard to work with. No free Arabic PDF tool handles table extraction well. This is a clear subscription justifier — users who need it will pay for it repeatedly.

Backend — FastAPI / PyMuPDF



# pip install pdfplumber openpyxl

# POST /api/pdf/extract-tables

# Body: { file: UploadFile, pages: list[int]|None, format: 'xlsx'|'csv'|'json' }



import pdfplumber

import openpyxl



def extract_tables(data: bytes, pages: list[int]|None, fmt: str) -> bytes:

all_tables = []

with pdfplumber.open(io.BytesIO(data)) as pdf:

for i, page in enumerate(pdf.pages):

if pages is None or i in pages:

tables = page.extract_tables()

for t in tables:

all_tables.append({'page': i+1, 'data': t})



if fmt == 'xlsx':

wb = openpyxl.Workbook()

for idx, tbl in enumerate(all_tables):

ws = wb.create_sheet(f'Page {tbl["page"]} Table {idx+1}')

for row in tbl['data']:

ws.append([cell or '' for cell in row])

wb.remove(wb['Sheet']) # remove default sheet

buf = io.BytesIO()

wb.save(buf)

return buf.getvalue()



if fmt == 'csv':

# Return ZIP of multiple CSVs if multiple tables

import csv, zipfile

buf = io.BytesIO()

with zipfile.ZipFile(buf, 'w') as zf:

for idx, tbl in enumerate(all_tables):

csv_buf = io.StringIO()

csv.writer(csv_buf).writerows(tbl['data'])

zf.writestr(f'table_{idx+1}_page_{tbl["page"]}.csv', csv_buf.getvalue())

return buf.getvalue()



pdfplumber is more accurate than PyMuPDF for table detection, especially for complex bordered tables. Install: pip install pdfplumber. For scanned PDFs (image-only), tables cannot be extracted without OCR — combine with your existing Tahweel OCR or Tesseract to make image cells searchable before extraction. Surface a warning to the user if no text layer is detected.

Frontend — React (Tauri)



Show an interactive table preview in the UI: render detected tables as HTML <table> elements with the raw extracted data. Let users deselect individual tables or rows before exporting. Format selector: XLSX / CSV / JSON. For multi-table results, show a numbered list of tables found with page attribution.

#6

Redact PDF

Estimate

4 days

Plan

Pro



Why build this now



Redaction is a compliance and legal requirement for government and healthcare users across KSA, Egypt, and the broader MENA region. It is never free in professional tools (Adobe Acrobat charges for it). Arabic text redaction (right-to-left search) is specifically broken in most Western tools — this is a strong differentiator.

Backend — FastAPI / PyMuPDF



# POST /api/pdf/redact

# Body: { file: UploadFile, search_terms: list[str] | None,

# manual_rects: list[{page, x0, y0, x1, y1}] | None,

# fill_color: [r,g,b] } # default [0,0,0]



def redact_pdf(data: bytes, search_terms: list[str]|None,

manual_rects: list[dict]|None,

fill_color: tuple = (0,0,0)) -> bytes:

doc = fitz.open(stream=data, filetype='pdf')



# 1. Search-based redaction

if search_terms:

for term in search_terms:

for page in doc:

# quads=True for RTL Arabic text accuracy

hits = page.search_for(term, quads=True)

for quad in hits:

page.add_redact_annot(quad, fill=fill_color)



# 2. Manual rectangle redaction

if manual_rects:

for r in manual_rects:

page = doc[r['page']]

rect = fitz.Rect(r['x0'], r['y0'], r['x1'], r['y1'])

page.add_redact_annot(rect, fill=fill_color)



# 3. Apply all redactions (permanently removes underlying content)

for page in doc:

page.apply_redactions(images=fitz.PDF_REDACT_IMAGE_PIXELS)



buf = io.BytesIO()

doc.save(buf, garbage=4, deflate=True, clean=True)

return buf.getvalue()



Use quads=True in search_for() for accurate Arabic text hit detection — Arabic ligatures and RTL direction cause standard rect-based search to miss characters. The images=PDF_REDACT_IMAGE_PIXELS flag ensures images under redaction rectangles are also permanently removed, not just covered. Always call doc.save(..., clean=True) to strip any recoverable data from the output.

Frontend — React (Tauri)



Two input modes: (1) Search & redact — text field supporting comma-separated terms, preview shows highlighted matches before committing; (2) Manual selection — render PDF page in viewer, let user draw rectangles over sensitive regions. Show a redaction summary: 'N areas redacted across P pages'. Warn prominently that redaction is permanent and cannot be undone.

#7

PDF Flatten + Remove Annotations

Estimate

2 days

Plan

Pro / Free



Why build this now



You already have a full annotation suite (Comments & Annotations tool). Flatten and Remove Annotations are the natural completion of that suite. Remove Annotations can be free-tier to drive tool discovery. Flatten (baking annotations into the page) is a Pro feature because it is used in professional document workflows.

Backend — FastAPI / PyMuPDF



# POST /api/pdf/remove-annotations

# Body: { file: UploadFile, types: list[str] | None }

# types: 'highlight','underline','strikeout','squiggly','text','stamp','ink','link'



def remove_annotations(data: bytes, types: list[str]|None) -> bytes:

doc = fitz.open(stream=data, filetype='pdf')

for page in doc:

for annot in list(page.annots()): # iterate copy — modifying during loop unsafe

if types is None or annot.type[1] in types:

page.delete_annot(annot)

buf = io.BytesIO()

doc.save(buf, garbage=4, deflate=True)

return buf.getvalue()



# POST /api/pdf/flatten

# Bakes annotations into page content permanently



def flatten_pdf(data: bytes) -> bytes:

doc = fitz.open(stream=data, filetype='pdf')

for page in doc:

page.clean_contents() # merge content streams

# Flatten form widgets

for widget in list(page.widgets() or []):

widget.update() # ensure current value rendered

page.clean_contents() # clean after widget update

buf = io.BytesIO()

doc.save(buf, garbage=4, deflate=True, clean=True)

return buf.getvalue()



Iterate annotations as list(page.annots()) — never iterate the live generator while deleting. For flattening, page.clean_contents() merges content streams but does not rasterize; for fully rasterized flattening (compatible with any viewer), use the pixmap approach from the Invert Colors feature. Offer both: 'Smart flatten' (clean_contents) and 'Full flatten' (rasterize).

Frontend — React (Tauri)



Remove Annotations: show an annotation type checklist (highlight, comment, underline, stamp, ink) with counts per type — your existing annotation scanner can supply this data. Flatten: simple single-action button with a brief explanation of what flatten means. Combine both into one 'Clean PDF' tool card for discoverability.

Shared implementation notes



Feature gating

All 6 features check useFeatureFlag() from the existing React context. No new gating infrastructure needed. Flatten and Remove Annotations share one flag ('clean_pdf'); crop, page-numbers, invert, extract-tables, and redact each have their own flag.

Background tasks

Redact and Extract Tables can be slow on large files. Route them through your existing background task system (FastAPI + task queue). Return a task ID immediately; poll /api/tasks/{id}/status from the frontend.

Arabic font

Download NotoNaskhArabic-Regular.ttf (Google Fonts, OFL license). Place in assets/fonts/. Reference by absolute path in PyMuPDF insert_text() calls. Do not rely on system fonts — they will be missing in production.

Error messages

Provide Arabic error messages alongside English for all 6 features. Scanned PDF warning ('لا يحتوي الملف على نص قابل للاستخراج') is especially important for Extract Tables and Redact search mode.

File size limits

Invert Colors rasterizes pages at 2x scale — a 200-page document may produce a very large output. Add a file-size warning for files >10MB and consider offering a 'low quality' (1x) invert mode.
